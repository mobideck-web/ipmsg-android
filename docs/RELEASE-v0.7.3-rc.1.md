# IPMsg for Android v0.7.3-rc.1

Initial public beta publication. Android 10+, application version 0.7.3 (code 11).

The latest camera wide view fills the receiver viewing ratio with centered cropping, without stretching or forcing browser full screen. Includes LAN messaging, individual files, local history/search, device approval, notifications and owner-controlled HTTPS camera with receiver-only captures.

Download IPMsg-v0.7.3-rc1.apk to install. Source ZIP is for developers. Install over an existing IPMsg/Lantern version to retain local history. Verify SHA256SUMS.txt if desired. Setup and camera guides and license notices are attached and in the repository.

**Known status:** this is a prerelease. The APK was compiled/shrunk/signed; latest UI/camera changes were not runtime-tested. Physical phone, Windows 5.9.1, Edge/Chrome, background/reconnection and sustained transfer acceptance remain pending. Historical tests do not certify this build. No cross-process transfer resume, folder transfers or live audio. Camera certificate setup depends on browser policy; classic IPMsg encrypted files do not authenticate contents.
