# Changelog

## 0.7.3-rc.1 — 2026-11-05

Android version 0.7.3, code 11. Initial GitHub publication of the existing signed APK.

- Live wide view fills the receiver viewport using centered cropping and natural proportions; normal fit view remains available.
- Added public installation, camera, build, privacy, security, contribution and license documentation. Application code/APK are unchanged from the previously delivered v0.7.3 build.
- Compiled/shrunk/signed. No new runtime tests. Physical phone/current Windows/browser acceptance pending.

## 0.7.2 — 2026-11-05

Wide in-window camera view instead of browser full screen. Manage storage moved into Storage settings.

## 0.7.1 — 2026-11-05

Separated conversation cards, grouped Settings, Nearby device management and widget removal. Simplified camera with stable-link quality percentage/native advertised stream output at 100%. Receiver-only JPEG/WebM downloads and sender activity alerts.

## Earlier development

History, Windows-compatible messages/files, device approval, transfer recovery, search, notifications and HTTPS camera were developed earlier. Reports under docs are historical and do not certify this release candidate.
